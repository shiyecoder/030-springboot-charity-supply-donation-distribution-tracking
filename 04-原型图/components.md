# 组件规范 · 公益物资捐赠与发放追踪系统

所有尺寸、颜色与 `design/mock.css` 一一对应，后续 Vue 实现必须 1:1 复刻，不得自行调参。

## 1. 按钮 Button

| 类型 | 类名 | 高度 | 内边距 | 背景 | 描边 | 文字 | 场景 |
|---|---|---|---|---|---|---|---|
| 主按钮 | `.btn.btn-primary` | 32px | 0 14px | `#19324A` | 同色 | `#fff` 500 | 新建、提交、推进状态 |
| 次按钮 | `.btn.btn-sub` | 32px | 0 14px | `#356A7A` | 同色 | `#fff` | 查询、确认拣货 |
| 普通按钮 | `.btn` | 32px | 0 14px | `#fff` | `#CBD5DE` | `#1D2A35` | 重置、导出、取消 |
| 危险按钮 | `.btn.btn-danger` | 32px | 0 14px | `#fff` | `#B02A37` | `#B02A37` | 拒收、作废、退回 |
| 小按钮 | `.btn.btn-sm` | 26px | 0 9px | 同类型 | 同类型 | 12px | 表格行内、卡片头 |

- 圆角 5px，图标与文字间距 6px
- hover：主按钮加深到 `#24435F`；描边按钮描边转 `#356A7A`
- 禁用：透明度 0.5，`cursor: not-allowed`，不改变尺寸
- 同一区域最多 1 个主按钮，位于最右侧

## 2. 表单 Form

| 控件 | 高度 | 宽度 | 说明 |
|---|---|---|---|
| `.input` | 32px | 默认 `w-md` 220px | 内边距 0 10px，描边 `#CBD5DE` |
| `.input.w-sm` | 32px | 150px | 数量、日期等短输入 |
| `.select` | 32px | **190–240px** | 搜索下拉固定此区间，禁止过窄或占满整行 |
| `.textarea` | ≥72px | 100%（表单内 520px） | 内边距 8px 10px，可纵向拖拽 |

- 表单标签宽 **100–120px**，单列输入宽度 **360–520px**
- 必填标记：标签后红色 `*`（`<em>*</em>`）
- 失焦校验，错误提示在控件下方 11px 红字，描边转 `#B02A37`
- 数字输入不显示步进器，右对齐，`tabular-nums`
- 文件上传：拖拽区 246×88，虚线 `#CBD5DE`，圆角 5px，显示「类型限制 / 大小限制」；已上传缩略图 78×60，右上角悬浮删除（二次确认）

## 3. 表格 Table

- 容器 `.table-wrap`：1px 描边 `#E3E8ED`，圆角 5px，横向溢出滚动
- 表头：背景 `#F7F9FA`，12px/600，文字 `#5B6B7A`，下边框 1px，**不固定宽度**，按内容自适应
- 数据行：13px，内边距 10px 12px，下边框 `#EEF2F5`，hover 背景 `#FAFBFC`
- 编号列：等宽字体 12px，颜色 `#356A7A`，字重 600
- 数字列：右对齐 + `tabular-nums`
- 带图列：缩略图 34×26（列表）/ 56×42（详情），圆角 4px，与两行文字间距 9px
- 操作列：行内最多「查看 + 2 个高频操作」，其余进「更多」；单行不换行
- 空状态：`.empty`，40px 上下留白，标题 13.5px 说明原因，副文案给出下一步

## 4. 卡片 Card

```
.card            白色 / 1px #E3E8ED / 圆角 7px / 内边距 18px 20px / 无阴影
.card-head       标题区，下间距 14px
  h2             14px 600
  .sub           12px #8A99A6，与标题间距 9px
  .actions       右对齐按钮组，间距 8px
```

- 卡片之间纵向间距 14px（`.card + .card`）
- 卡片内不再套白底卡片，需要分组时用 `.summary-box`（背景 `#F7F9FA`）

| `.tag-warn` | `#A8761C` | `#FCF5E8` | `#EFDFBE` | 待处理、临期 |
| `.tag-danger` | `#B02A37` | `#FBF1F2` | `#EFCDD1` | 驳回、过期、异常 |

## 6. 弹窗与抽屉

- **抽屉**（审批、状态流转、批量操作）：宽 520px，右侧滑入，遮罩 `rgba(20,32,44,.32)`
  - 头部 52px（标题 15px/600 + 关闭按钮）
  - 主体滚动区，内边距 18px 20px，首个元素为 `.summary-box` 单据摘要
  - 底部 12px 20px，按钮右对齐，主按钮在最右
- **弹窗**（二次确认）：宽 420px，圆角 7px，`--shadow`，标题 15px，正文 13px，按钮右对齐
- 危险操作确认文案必须写清后果与影响条数，例如「将拒收该批次 200 件，操作后不可撤销」

## 7. 分页 Pager

```
共 328 条   [10 条/页 ▾]   上一页  1 2 3 4 5 6  下一页
```

- 页码按钮 27×27，圆角 4px，当前页背景 `#19324A` 白字
- 每页条数可选 10 / 20 / 50，默认 10
- 切换筛选条件后页码回到第 1 页
- 服务端分页，前端只传 `page` / `size` / 排序字段

## 8. 图表

| 图表 | 实现 | 规格 |
|---|---|---|
| 趋势折线 | ECharts line，双系列 | 高 110px，主线 `#19324A` 2px，虚线系列 `#356A7A` |
| 分类柱状 | ECharts bar | 柱宽 ≤34px，主色渐变 `#356A7A → #19324A`，次系列 `#7FA3B2 → #456C7E` |
| 状态环图 | ECharts pie（ring） | 内径 24px 留白，中心显示总数 + 单位 |
| 排行条 | 纯 CSS `.hbar` | 轨道高 9px，圆角 5px，数值右对齐 |
| 达成率 | 纯 CSS `.progress` | 高 6px，正常 `#356A7A`，达成 100% 转 `#2B7955` |
| 评分条 | 纯 CSS `.factor` | 轨道高 7px，得分列右对齐加粗主色 |

- 图例统一在图表下方或右侧，字号 11px
- 图表点击必须能跳到带对应筛选条件的列表，统计值与明细总数一致
- 所有图表容器高度写死，禁止因数据变化导致看板出现滚动条

## 12. 上传组件

- 触发区 246×88 虚线框，或 78×60 缩略图位
- 上传中显示进度条与百分比，禁止只转圈
- 类型限制 `JPG / PNG / PDF`，大小 ≤5MB（附件 ≤20MB）
- 上传成功回填相对路径 `/uploads/seed/<实体>/NN.jpg`，禁止手填 URL
- 删除需二次确认，删除后同步删除服务端文件记录

## 13. 消息与提示

- 顶栏消息图标 + 红点（未读 >0），点击进消息中心
- 消息条目含：类型标签、正文（含业务编号）、时间、已读状态、跳转操作
- 业务成功用绿色轻提示 2s 自动消失；失败用红色提示并保留，需手动关闭
- 表单校验失败滚动定位到第一个错误字段
