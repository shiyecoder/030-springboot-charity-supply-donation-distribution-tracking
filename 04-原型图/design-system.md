# 公益物资捐赠与发放追踪系统 · 设计系统

> 视觉方向：**数据钢蓝**。面向社会组织的物资追溯业务系统，重点是可读性、操作效率与状态辨识，
> 不使用巨幅英文口号、装饰性光效、悬浮球、过度渐变或大面积插画。
> 主色取自需求文档「UI 视觉与交互设计」一节，不允许自行替换。

## 1. 色彩

| 用途 | 色值 | 变量 | 具体用法 |
|---|---|---|---|
| 主色 | `#19324A` | `--primary` | 顶部栏、主按钮、当前菜单、关键数字 |
| 辅助色 | `#356A7A` | `--sub` | 次级按钮、筛选选中态、常规图表系列 |
| 页面背景 | `#F4F6F8` | `--bg` | 主内容区背景，表格与表单用白色容器 |
| 强调色 | `#456C7E` | `--accent` | 链接、信息提示、图表对比系列 |
| 成功色 | `#2B7955` | `--success` | 已完成、已通过、正常 |
| 危险色 | `#B02A37` | `--danger` | 驳回、超时、异常、删除确认（小面积） |
| 警示色 | `#A8761C` | `--warn` | 临期、待办、即将超时 |
| 分割线 | `#E3E8ED` / `#CBD5DE` | `--line` / `--line-strong` | 卡片描边 / 输入框描边 |
| 主文字 | `#1D2A35` | `--text` | 正文、表格内容 |
| 次文字 | `#5B6B7A` | `--text-2` | 标签、说明 |
| 弱文字 | `#8A99A6` | `--text-3` | 占位、时间戳、辅助信息 |

图表颜色从主色、辅助色、强调色与中性灰派生，同一含义在不同页面保持一致。
**状态不允许只用颜色表达**：所有状态标签同时显示中文文字（如「临期」「已退回」），并在标签前加 5px 圆点。

## 2. 字体阶梯

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 19px / 1.4 | 600 | 页面标题 |
| H2 | 14px / 1.4 | 600 | 卡片标题 |
| H3 | 13px / 1.4 | 600 | 图表标题 |
| 正文 | 13px / 1.6 | 400 | 表格、表单、说明 |
| 辅助 | 12px / 1.6 | 400 | 标签、筛选条件、字段名 |
| 弱化 | 11px / 1.5 | 400 | 时间戳、提示、图表轴 |
| 关键数字 | 23px / 1.2 | 600 | KPI 主数值 |
| 编号 | 13px / 1.4 | 600 | 业务编号（等宽字体） |

- 字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字列统一 `font-variant-numeric: tabular-nums`，保证位数对齐
- 业务编号使用 `ui-monospace, Menlo, monospace`，防止 0/O、1/l 混淆

## 3. 空间与圆角

- 侧边栏宽 **232px**，顶栏高 **56px**，内容区外边距 **24px**
- 卡片内边距 **18px 20px**，卡片间距 **14px**
- 圆角：卡片 **7px**，按钮/输入框 **5px**，标签 **4px**，图标按钮 **5px**
- 表格行高：表头 38px、数据行 41px，单元格左右内边距 12px
- 阴影只用于抽屉（`-6px 0 26px rgba(25,50,74,.14)`）与弹窗，卡片只用 1px 描边

## 4. 布局骨架

**管理端（项目管理员 / 受助审核员 / 仓储志愿者）**

```
┌─ 232px 侧边栏 ─┬──────────── 内容区 ────────────┐
│ Logo 56px      │ 顶栏 56px：面包屑 · 消息 · 头像 │
│ 分组菜单       │ 24px padding                    │
│ （深色 #19324A）│ 页面标题 + 说明 + 操作按钮      │
│                │ 筛选区 → 表格区 → 分页          │
└────────────────┴────────────────────────────────┘
```

**普通用户端（捐赠人 / 受助人）** 用门户风格：深色横向导航 60px + 最大宽 1220px 居中内容区，
不使用侧边栏，首页用 `phero` 深色横幅承载「项目进展 + 关键数字」。

## 7. 一屏规范（1440×900）

看板页严格一屏，不出现纵向滚动条：

- 顶栏 56 + 内容区上下 padding 48 + 页面标题 66 = 170
- KPI 行 6 张卡（高 88） + 14 间距 = 102
- 图表区两行各 178 + 12 间距，加第三行 130 = 498
- 合计约 770，留 130 余量

其他页面允许纵向滚动，但首屏必须能看到「标题 + 筛选 + 至少 6 行数据」。

## 8. 交互基调

- 加载超过 300ms 显示表格局部 loading，禁止整页白屏
- 危险操作（拒收、作废、退回、删除）用红色描边按钮 + 二次确认
- 审批与状态流转统一走右侧抽屉（520px），抽屉内带单据摘要
- 空状态必须说明原因与下一步：「当前筛选条件下无记录，清空筛选或新建发放追踪单」
- 表格行内最多「查看 + 2 个高频操作」，其余收进「更多」
- 表单关闭前检测未保存内容；复杂表单支持「保存草稿」
- 日期、人员、组织、字典、级联一律用专用组件，不用文本框代替

## 9. 响应式

| 断点 | 行为 |
|---|---|
| ≥1440px | 标准三栏布局，看板 6 KPI + 3 列图表 |
| 1024–1440px | 侧边栏可折叠为图标（保留悬浮说明），图表降为 2 列 |
| 768–1024px | 侧边栏变抽屉，KPI 两行三列 |
| <768px | 表格改信息卡片（只留编号/状态/时间/负责人），筛选折叠为底部面板，主按钮固定安全区 |

移动端点击区不小于 44px，底部固定操作区不得遮挡分页与导航。
